# 🏦 多地址模式配置指南

## 📋 什么是多地址模式？

多地址模式下，每个 AI 使用独立的 Hyperliquid 地址：
- ✅ 6 个 AI = 6 个独立地址
- ✅ 资金完全隔离
- ✅ 真实的独立交易
- ✅ 符合 nof1.ai 的真实竞技模式

---

## 🔧 配置步骤

### 步骤 1：准备 6 个 Hyperliquid 地址

你需要准备 6 个地址的私钥：

**测试网：**
```bash
# 可以用脚本快速生成 6 个
for i in {1..6}; do python3 generate_account.py; done
```

**主网：**
- 使用你已有的 6 个钱包私钥
- 或创建 6 个新钱包（MetaMask、硬件钱包等）
- 确保每个地址都有足够的 USDC

---

### 步骤 2：充值每个地址

**建议配置：**
```
每个地址: 100 USDC
总计: 600 USDC
```

**最低配置：**
```
每个地址: 50 USDC
总计: 300 USDC
```

---

### 步骤 3：配置 .env 文件

编辑 `.env` 文件：

```bash
nano .env
```

添加配置：

```bash
# ============================================================
# 主网/测试网选择
# ============================================================
HYPERLIQUID_TESTNET=False  # False = 主网, True = 测试网

# ============================================================
# AI API Keys
# ============================================================
CLAUDE_API_KEY=sk-ant-xxx...
OPENAI_API_KEY=sk-proj-xxx...
GEMINI_API_KEY=AIza...
QWEN_API_KEY=sk-xxx...
GROK_API_KEY=xai-xxx...
DEEPSEEK_API_KEY=sk-xxx...

# ============================================================
# 多地址模式 - 每个 AI 的独立私钥
# ============================================================
# 格式：0x + 64位十六进制字符

# Claude 的地址私钥
CLAUDE_PRIVATE_KEY=0x1234567890abcdef...

# GPT-4 的地址私钥
GPT_PRIVATE_KEY=0x1234567890abcdef...

# Gemini 的地址私钥
GEMINI_PRIVATE_KEY=0x1234567890abcdef...

# Qwen 的地址私钥
QWEN_PRIVATE_KEY=0x1234567890abcdef...

# Grok 的地址私钥
GROK_PRIVATE_KEY=0x1234567890abcdef...

# DeepSeek 的地址私钥
DEEPSEEK_PRIVATE_KEY=0x1234567890abcdef...

# ============================================================
# AI 交易配置
# ============================================================
AI_INITIAL_BALANCE=100.0  # 这个值会被实际余额覆盖
AI_MAX_POSITION_SIZE=30.0  # 单笔最大仓位（建议账户的30%）
ARENA_UPDATE_INTERVAL=600  # 10分钟

# ============================================================
# 风险管理
# ============================================================
DAILY_LOSS_LIMIT=50.0  # 单日最大亏损（建议账户的50%）
MAX_LEVERAGE=2  # 最大杠杆（主网建议2-3倍）
```

## 💰 成本估算

### 测试配置（每个地址 100U）
```
初始投入: $600
手续费: ~0.02% × 交易次数 × 6
AI API 成本: ~$15-20/天

每天总成本: $15-25
适合: 短期测试（1-2周）
```

### 正式配置（每个地址 500U）
```
初始投入: $3000
手续费: ~0.02% × 交易次数 × 6
AI API 成本: ~$15-20/天

每天总成本: $15-25
适合: 长期运营（1-3个月）
```

## ⚠️  安全建议

### 1. 私钥管理
- ✅ 永远不要泄露私钥
- ✅ .env 文件已在 .gitignore 中
- ✅ 不要提交到 git
- ✅ 使用独立的交易钱包，不要用主钱包

### 2. 资金安全
- ✅ 从小额开始测试（100U/地址）
- ✅ 设置合理的止损限制
- ✅ 定期检查盈亏情况
- ✅ 不要使用过高杠杆

### 3. 风险控制
```bash
# 建议配置
DAILY_LOSS_LIMIT=50.0      # 单日最大亏损
MAX_LEVERAGE=2             # 最大杠杆 2x
AI_MAX_POSITION_SIZE=30.0  # 单笔最大30U
```

## ❓ 常见问题

### Q: 可以只配置部分 AI 吗？
A: 可以！只配置你想要的 AI 的 API Key 和私钥即可。

### Q: 某个 AI 亏完了怎么办？
A: 该 AI 会自动停止交易（余额不足）。其他 AI 继续运行。

### Q: 可以随时充值吗？
A: 可以！直接向对应地址转入 USDC 即可。

### Q: 如何切换测试网/主网？
A: 修改 `.env` 中的 `HYPERLIQUID_TESTNET=True/False`

### Q: 手续费大概多少？
A: Hyperliquid 手续费约 0.02%，每天交易10次，每笔30U：
```
30 × 10 × 6 × 0.02% = $0.36/天
```
