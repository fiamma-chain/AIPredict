

# 🗳️ AI 共识决策模式

## 📋 什么是共识模式？

共识模式是一种更稳健的交易策略，通过多个 AI 的集体投票来做出决策，而不是依赖单个 AI 的判断。

### 核心理念
- **集体智慧** > 个体决策
- **多数决** > 一言堂
- **降低错误** > 追求极致

## 🗳️ 投票机制

### 投票流程

```
1. 获取市场数据
   ↓
2. 每个 AI 独立分析
   ├─ Claude: BUY, 80%
   ├─ GPT-4: BUY, 75%
   └─ Gemini: HOLD, 60%
   ↓
3. 统计投票结果
   BUY: 2 票
   HOLD: 1 票
   ↓
4. 判断共识
   2/3 ≥ 2 → ✅ 达成共识
   ↓
5. 执行交易
   决策: BUY
   置信度: (80+75+60)/3 = 71.7%
```

### 共识阈值

```python
consensus_threshold = 2  # 至少2个AI同意

# 3个AI的组
3个AI中至少2个同意 = 2/3 = 66.7%

# 如果有4个AI
4个AI中至少3个同意 = 3/4 = 75%
```

## 📊 决策规则

### 何时开仓

```
条件（AND）：
1. ✅ 至少 2/3 AI 决策为 BUY 或 STRONG_BUY
2. ✅ 当前没有持仓
3. ✅ 通过风险检查
4. ✅ 账户余额充足

仓位计算：
平均置信度 = (AI1置信度 + AI2置信度 + AI3置信度) / 3
仓位大小 = 账户余额 × 基础比例 × 平均置信度
```

### 何时平仓

```
条件（OR）：
1. ✅ 至少 2/3 AI 决策为 SELL 或 STRONG_SELL
2. ✅ 触发止损（亏损 > 20%）
3. ✅ 触发止盈（盈利 > 30%）
4. ✅ 单日亏损超限
```

### 意见分歧时

```
情况 1: 完全分歧
Claude: BUY
GPT-4: HOLD
Gemini: SELL
→ 未达成共识，不执行

情况 2: 多数同意
Claude: BUY
GPT-4: BUY
Gemini: HOLD
→ 达成共识，执行 BUY

情况 3: 强弱不同
Claude: STRONG_BUY
GPT-4: BUY
Gemini: BUY
→ 统计为 BUY 类别，达成共识
```

## 🆚 共识模式 vs 独立模式

| 特性 | 独立模式 | 共识模式 |
|------|---------|---------|
| 决策方式 | 单个AI独立 | 多个AI投票 |
| 交易频率 | 高 | 中低 |
| 决策稳定性 | 低 | 高 |
| 风险控制 | 个体依赖 | 集体验证 |
| 账户数量 | 6个 | 2个 |
| 初始投入 | $600 (6×100) | $200 (2×100) |
| 适合场景 | 看各AI特点 | 稳健交易 |

## 📈 优势分析

### 1. 降低错误率
- 单个AI的错判不会立即执行
- 需要多数同意才能交易
- 类似"第二意见"机制

### 2. 提高决策质量
- 综合多个AI的分析
- 平衡不同视角
- 减少极端决策

### 3. 更好的风险管理
- 意见分歧时不交易
- 避免冲动决策
- 保守但稳健

### 4. 降低成本
- 只需2个账户（vs 6个）
- 初始投入减少67%
- 手续费降低


- 观察共识达成率
- 查看哪些场景容易分歧
- 分析盈亏原因

### 3. 优化调整
- 如果共识率太低（<30%）→ 降低阈值或调整AI组合
- 如果亏损较多 → 增加更新间隔，降低仓位
- 如果某个组表现优异 → 可以增加该组资金

## ❓ 常见问题

### Q: 为什么交易频率变低了？
A: 共识模式需要多个AI同意，自然会降低交易频率。这是特性，不是bug。

### Q: 某个组一直不交易？
A: 可能是意见分歧太大。查看日志中的投票详情，可能需要调整阈值。

### Q: 可以改为4个AI一组吗？
A: 可以！修改代码中的分组逻辑即可。

### Q: 共识模式成本更低吗？
A: 是的。只需2个地址（200U）vs 6个地址（600U）。

### Q: 哪种模式更好？
A: 
- 共识模式：更稳健，适合长期运营
- 独立模式：更激进，适合对比测试
