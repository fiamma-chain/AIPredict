# 🎯 AI Trading Arena - 交易策略说明

## 📋 策略概览

系统采用 **AI 驱动的决策 + 规则化执行** 模式：
- ✅ AI 负责分析市场并给出决策
- ✅ 系统根据决策自动执行开平仓
- ✅ 内置风险控制和仓位管理

---

## 🤖 AI 决策机制

### 1. 决策类型
AI 可以给出 5 种决策：

| 决策 | 说明 | 仓位比例 | 触发条件 |
|------|------|---------|---------|
| `STRONG_BUY` | 强烈买入 | 15% × 置信度 | 没有持仓时开多 |
| `BUY` | 买入 | 10% × 置信度 | 没有持仓时开多 |
| `HOLD` | 持有 | 0% | 不操作 |
| `SELL` | 卖出 | 平仓 100% | 有持仓时平仓 |
| `STRONG_SELL` | 强烈卖出 | 平仓 100% | 有持仓时平仓 |

### 2. AI 分析内容

AI 会分析以下数据：
```python
# 市场数据
- 当前价格
- 24小时成交量
- 资金费率
- 未平仓合约

# 订单簿深度（前5档）
- 买盘深度和价格
- 卖盘深度和价格

# 持仓状态（如果有）
- 入场价格
- 持仓大小
- 未实现盈亏
```

AI 会考虑：
1. 价格趋势和动量
2. 订单簿流动性和深度
3. 资金费率情况
4. 成交量和未平仓合约
5. 市场情绪和风险

### 3. 置信度机制

AI 给出的置信度（0-100）会影响仓位大小：
```python
实际仓位 = 基础比例 × (置信度 / 100)

例如：
BUY + 置信度 80% → 仓位 = 10% × 0.8 = 8%
STRONG_BUY + 置信度 90% → 仓位 = 15% × 0.9 = 13.5%
```

## 📊 开仓策略

### 开仓条件（同时满足）

```python
1. AI 决策 = BUY 或 STRONG_BUY
2. 当前没有持仓（不重复开仓）
3. 置信度 > 0
4. 通过风险检查
```

### 开仓流程

```
1. AI 分析市场 → 决策: BUY, 置信度: 75%
                ↓
2. 计算仓位大小
   当前余额: $100
   基础比例: 10%
   置信度调整: 75%
   仓位大小: $100 × 10% × 0.75 = $7.5
   不超过最大仓位: min($7.5, $30) = $7.5
                ↓
3. 风险检查
   ✓ 账户余额充足
   ✓ 单日亏损未超限
   ✓ 持仓数量未超限
   ✓ 杠杆倍数未超限
                ↓
4. 下单执行
   类型: 市价单
   方向: 买入（做多）
   数量: $7.5 / 当前价格
                ↓
5. 记录持仓
   入场价格
   持仓数量
   入场时间
```

### 开仓参数

```python
# 基础仓位比例
BUY: 10% 的账户余额
STRONG_BUY: 15% 的账户余额

# 最大单笔仓位
AI_MAX_POSITION_SIZE = 30.0  # 建议值（可在 .env 配置）

# 实际仓位计算
position_value = balance × base_ratio × (confidence / 100)
position_value = min(position_value, MAX_POSITION_SIZE)
```

## 📉 平仓策略

### 平仓条件（满足任一）

```python
1. AI 主动平仓
   - AI 决策 = SELL 或 STRONG_SELL
   - 且有持仓

2. 风险管理平仓（自动）
   - 触发止损（亏损达到阈值）
   - 触发止盈（盈利达到目标）
   - 单日亏损超限
```

### AI 主动平仓流程

```
1. AI 分析持仓 → 决策: SELL
                ↓
2. 获取持仓信息
   入场价格: $50,000
   当前价格: $51,000
   持仓数量: 0.001 BTC
   未实现盈亏: +$1
                ↓
3. 创建平仓订单
   类型: 市价单
   方向: 卖出
   数量: 0.001 BTC (全部平仓)
                ↓
4. 下单执行
                ↓
5. 计算盈亏
   盈亏: ($51,000 - $50,000) × 0.001 = $1
   盈亏比例: +2%
                ↓
6. 更新账户
   余额: +$1
   总交易数: +1
   胜率更新
   记录交易历史
                ↓
7. 移除持仓记录
```

### 风险管理平仓

系统会自动检查并平仓：

```python
# 止损
if 持仓亏损 >= 账户的 20%:
    自动平仓

# 止盈
if 持仓盈利 >= 账户的 30%:
    自动平仓

# 单日亏损限制
if 当日总亏损 >= DAILY_LOSS_LIMIT:
    停止所有交易
```

## 🔄 交易周期

### 典型的交易周期

```
1. 竞技场启动
   ↓
2. 每 10 分钟执行一次周期
   ↓
3. 更新所有持仓状态
   ↓
4. 风险检查（止损/止盈）
   ↓
5. 每个 AI 分析每个交易对
   - BTC, ETH, SOL
   - 共 6 个 AI × 3 个币种 = 18 次分析
   ↓
6. 根据 AI 决策执行交易
   ↓
7. 更新排行榜
   ↓
8. 等待下一个周期
```

### 并行执行

```python
# 所有 AI 的分析是并行的
Claude 分析 BTC  ┐
GPT-4 分析 BTC   │
Gemini 分析 BTC  ├─ 同时执行
Qwen 分析 BTC    │
Grok 分析 BTC    │
DeepSeek 分析 BTC┘
```

## 📈 实际案例

### 案例 1：成功的多头交易

```
时间: 10:00
AI: Qwen
币种: BTC
当前价格: $50,000

1. AI 分析
   决策: STRONG_BUY
   置信度: 85%
   理由: "突破关键阻力位，成交量放大，订单簿买盘深度增加"

2. 计算仓位
   账户余额: $100
   仓位: $100 × 15% × 0.85 = $12.75
   实际: min($12.75, $30) = $12.75

3. 开仓
   买入: $12.75 / $50,000 = 0.000255 BTC @ $50,000

─────────────────────────────────────────

时间: 10:30
价格: $52,000

AI 分析
   决策: HOLD
   持仓未实现盈亏: +$0.51 (+4%)

─────────────────────────────────────────

时间: 11:00
价格: $51,500

AI 分析
   决策: SELL
   理由: "达到目标位，出现反转信号"

4. 平仓
   卖出: 0.000255 BTC @ $51,500
   盈亏: ($51,500 - $50,000) × 0.000255 = $0.38
   盈亏率: +3%

5. 结果
   账户余额: $100 → $100.38
   ROI: +0.38%
   交易数: +1
   胜率: 100%
```

## 🎯 策略优化建议


适合：新手、小资金、测试阶段

```bash

DAILY_LOSS_LIMIT=50.0        # 50% 日限
```

适合：有经验、中等资金、日常运营

```bash

```

适合：专业交易者、大资金、短期测试

## ⚠️ 风险提示

### 策略限制

1. **只做多**
   - 当前只支持做多（买入开仓）
   - 不支持做空

2. **市价单**
   - 所有订单都是市价单
   - 可能有滑点

3. **单次持仓**
   - 每个币种同时只能有一个持仓
   - 不支持加仓

4. **止损机制**
   - 依赖系统定期检查
   - 极端行情可能超过预期亏损

### 使用建议

1. ✅ 从小资金开始（100U）
2. ✅ 先在测试网运行几天
3. ✅ 观察每个 AI 的表现
4. ✅ 根据实际情况调整参数
5. ✅ 设置合理的止损止盈
6. ✅ 定期监控系统运行

## 💡 常见问题

**Q: 为什么 AI 分析后不开仓？**
A: 可能原因：
- 置信度太低
- 风险检查不通过
- 已有持仓（不重复开仓）
- 账户余额不足

**Q: 如何调整交易频率？**
A: 修改 `ARENA_UPDATE_INTERVAL`，单位是秒

**Q: 可以只做特定币种吗？**
A: 可以修改 `arena/ai_arena.py` 中的 `trading_pairs`

**Q: 如何看每笔交易的详细信息？**
A: 每个 AI 的 `trade_history` 记录了所有交易
