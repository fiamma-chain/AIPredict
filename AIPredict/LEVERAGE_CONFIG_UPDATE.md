# 杠杆和保证金配置升级说明

## 📋 配置变更总结

### 原配置
- **保证金**: $120 - $240
- **杠杆**: 2x - 5x
- **最大仓位**: $1,200 (信心度100%: $240 × 5x)

### 新配置 ✨
- **保证金**: $200 - $500
- **杠杆**: 5x - 20x
- **最大仓位**: $10,000 (信心度100%: $500 × 20x)

## 🔧 修改的文件

### 1. `config/settings.py`
添加了 `ai_min_leverage` 配置项，并更新了相关值：

```python
ai_min_margin: float = 200.0     # 最小保证金（U）- 从 120 改为 200
ai_max_margin: float = 500.0     # 最大保证金（U）- 从 240 改为 500
ai_min_leverage: float = 5.0     # 最小杠杆倍数 - 新增配置
ai_max_leverage: float = 20.0    # 最大杠杆倍数 - 从 5 改为 20
```

### 2. `trading/auto_trader.py`
- 添加 `self.min_leverage` 属性读取配置
- 更新杠杆计算公式，使用配置的最小杠杆而非硬编码的 2.0
- 更新日志输出，显示完整杠杆范围
- 更新杠杆参数传递时的最小值检查

**关键修改**：
```python
# 原代码（硬编码 2.0）
leverage = 2.0 + ((confidence - 50.0) / 50.0) * (self.max_leverage - 2.0)
leverage = max(2.0, min(leverage, self.max_leverage))

# 新代码（使用配置）
leverage = self.min_leverage + ((confidence - 50.0) / 50.0) * (self.max_leverage - self.min_leverage)
leverage = max(self.min_leverage, min(leverage, self.max_leverage))
```

### 3. `env.example.txt`
更新了配置示例和计算公式说明，展示新的杠杆范围。

## ⚠️ 风险提醒

### 1. **账户余额要求**
- **最小余额**: 建议至少 $500（支持最大仓位）
- **推荐余额**: $1,000+ （留有安全边际）

### 2. **风险放大**
- **原配置**: 最大亏损 $180 (15% × $240 × 5x)
- **新配置**: 最大亏损 $750 (15% × $500 × 20x)
- **风险增加**: 4.2倍

### 3. **爆仓风险**
使用20倍杠杆，价格反向波动 **5%** 即可导致爆仓！

**计算**：
- 止损 15% × 20倍 = 300% 账户亏损（超过100%即爆仓）
- 实际爆仓线：约 5% 价格反向波动

### 4. **建议措施**
1. **初始资金**: 确保账户至少 $500
2. **分散风险**: 不要全仓使用最大杠杆
3. **止损纪律**: 严格执行 15% 止损（系统已自动执行）
4. **信心度门槛**: 保持 50% 以上才开仓（已配置）
5. **监控波动**: 高杠杆时密切关注市场
